# Render 备用后端

状态：部署代码与配置已准备；尚未创建 Render 服务，线上默认接口仍为 Sites。仅准备配置不代表安卓访问问题已解决。必须取得实际部署地址并用发生问题的安卓手机验证，再切换网页。

## 为什么准备独立后端

安卓浏览器直接打开当前 `chatgpt.site` 服务地址时显示 `Sorry, you have been blocked`，现有服务日志也没有对应安卓请求。请求在进入业务接口前被拦截，修改反馈表单或 GitHub Token 不能解决这个入口问题。

备用服务直接运行 `server/cloud` 中的 Node 后端，同时处理 DeepSeek 和 GitHub 反馈；不会转发到原 Sites 域名。前端和代码仍在现有 GitHub 仓库，反馈仍存入 `RosannaBebe/zonghe-ai-feedback` 私有仓库。

## 免费托管边界

- Render 提供 `*.onrender.com` HTTPS 地址，无需购买域名和服务器。
- 本仓库 Blueprint 指定 Free 方案与 Singapore 区域；不包含付费实例、数据库或磁盘。账号若要求付款或升级，先停止，不自动同意。
- 免费 Web Service 闲置 15 分钟会休眠，再次启动约需一分钟；每工作区每月有 750 免费实例小时。平台规则与额度以创建时显示为准。
- 免费的是后端托管，DeepSeek 仍使用现有 API 账户额度。
- 新域名是否能被指定安卓浏览器及其网络访问，必须实测；托管方案不能保证所有地区和网络的连通性。

官方依据：[免费服务](https://render.com/docs/free)、[Web Service](https://render.com/docs/web-services)、[Blueprint 配置](https://render.com/docs/blueprint-spec)、[环境变量](https://render.com/docs/configure-environment-variables)。

## 部署步骤

1. 完成 Render 账号连接。若需创建账号、确认条款或授权 GitHub，由账号所有者完成。
2. 在 Render 使用 Blueprint 关联本仓库，读取根目录 `render.yaml`。也可以从 [Deploy to Render](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FRosannaBebe%2Fzonghe-ai-assistant) 开始。确认方案为 **Free**。
3. 在 Render 的秘密环境变量中配置以下已有值：`DEEPSEEK_API_KEY`、`DEMO_ACCESS_TOKEN`、`FEEDBACK_GITHUB_TOKEN`、`FEEDBACK_ADMIN_TOKEN`。不要放入仓库、网页字段或聊天截图。模型和管理口令分别至少 24 字符。`FEEDBACK_SIGNING_SECRET` 由 Blueprint 自动生成。
4. 其余来源、模型、反馈仓库、Node 24、监听与健康检查配置由 Blueprint 提供。服务使用 Render 注入的 `PORT`，不手填网站端口。
5. 等待部署成功并记录 Render 实际返回的域名，不能根据服务名称猜测域名。首次打开服务根地址，应该显示“服务地址可以访问”。`/health` 返回成功只表示进程存活，不代表第三方凭据已验证。

GitHub 凭据仍使用仅授权反馈仓库的 fine-grained Token，Issues 为 Read and write；不能替换成账号级 `repo` Token。适配器会额外读取仓库 metadata，确认目标为私有且启用了 Issues。Fine-grained Token 自带 Metadata 读取权限。

## 上线验收与切换

1. 先让同一安卓浏览器打开新服务根地址，确认不再出现拦截页面。免费实例刚唤醒时允许约一分钟启动。
2. 从 GitHub Pages 来源验证票据申请、一次明确标注的反馈测试、相同编号重试不重复写入、管理口令读取；不在测试日志输出反馈正文、密钥或完整请求头。
3. 验证真实 DeepSeek 规划与生成。访问口令错误、非允许来源、超过 1000 字反馈应被拒绝。
4. 验证通过后，将 `src/feedback.js` 中的默认反馈地址（票据地址自动由它推导），以及 `src/app.js` 中默认模型生成地址改为实际新域名，提交并等待 GitHub Pages 发布。不要改变路径 `/api/feedback`、`/api/feedback-ticket`、`/api/generate`。
5. 已保存旧模型接口的浏览器要在“模型与数据设置”更新为新域名的完整 `/api/generate` 地址。模型访问口令仍只保存在当前标签页会话，需要重新填写时由维护者提供。
6. 最后由原先失败的安卓手机提交一条反馈，并确认反馈列表出现记录，才可报告手机端修复成功。

前端已准备仅针对 `https://*.onrender.com` 的连接等待：先访问不带口令和业务文字的健康接口，成功后才申请反馈票据或发送模型任务。最长等待 90 秒；关闭反馈弹窗后提交会继续，退出管理列表会取消该列表的请求。不会自动重发反馈 POST。现有 Sites 地址不触发这个额外流程。

## 本地检查与维护

Node 要求至少 22.18，Render 固定使用 24 主版本。无需安装运行依赖：

```sh
node --test server/cloud/tests/*.test.mjs
node --env-file=server/cloud/.env.local server/cloud/adapter.mjs
```

`.env.local` 仅用于本机，由 `server/cloud/.env.example` 复制并填写，不加入 Git。`server/cloud/SOURCE.md` 记录处理器来源和限流、去重边界。

Blueprint 在 Render Free 公网服务启用 `TRUST_RENDER_EDGE=true`，使用平台覆盖的 `CF-Connecting-IP` 区分网络来源，不信任可伪造的 XFF 链。缺少有效地址时反馈返回配置错误，健康页仍可访问。改到其他托管、私网入口或付费服务前，必须重新确认这条代理信任边界；本机默认关闭。该部署为公司共用网络预留每 IP 每 10 分钟 120 次票据、60 次提交，另有每进程每 10 分钟 200 次提交上限；它们是试用额度，不是用户身份认证。

保留原 Sites 服务，直到安卓与电脑验收通过。需要回滚时，恢复上一次已验证的前端接口配置并发布；后台写入同一个反馈仓库，已有反馈无需迁移。
